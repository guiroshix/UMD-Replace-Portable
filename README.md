# UMD-Replace but compiled into more than one executable file.

- Original Project by CUE, 2015.
- Modified project by Guiroshix | BomberME

# What are the differences?
- You can run it on pretty much anything that has a terminal, Windows, Linux, Android.

# How does it work?
- The syntax is `UMD-REPLACE imagename filename newfile`
- Call UMD-Replace, in the first arg you put the path of your ISO, the second is the file you want to replace inside the UMD file, you can use `/` and `\`, and the third file is the path to generate the new file.
